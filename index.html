참고: 클룩 공식 프로모션 페이지(제휴 혜택 모음)에서 연중 진행되는 모든 이벤트와 제휴 할인 정보 확인이 가능합니다. 각 프로모션별 제공 사항, 기간, 규정이 상이하며 예고 없이 변경될 수 있으므로, 예약 전 최신 정보 확인이 권장됩니다.

클룩 할인코드 FAQ

자주 묻는 질문과 답변입니다. 클릭 시 답변이 표시됩니다.

Q1. 클룩 할인코드(쿠폰코드)란 무엇인가요? ▼

클룩 할인코드는 예약 시 입력하면 일정 금액 또는 비율이 할인되는 코드입니다. 클룩 웹사이트나 앱의 프로모션을 통해 배포되며, 기간 한정 이벤트나 신규회원 혜택 등의 형태로 제공됩니다. 새로운 쿠폰 코드가 수시로 추가되므로 클룩 프로모션 페이지 및 이메일 뉴스레터에서 확인 가능합니다.

Q2. 할인코드는 어떻게 받거나 확인할 수 있나요? ▼

클룩의 할인코드는 이벤트 페이지에서 코드명을 확인하거나 앱 또는 웹 내 계정의 쿠폰함에서 받을 수 있습니다. 웹사이트의 경우 우측 상단 프로필 메뉴의 쿠폰 페이지에서 보유 중인 쿠폰 코드를 확인할 수 있고, 앱에서는 MY클룩 메뉴의 쿠폰 배너를 통해 확인 가능합니다. 프로모션에 따라서는 쿠폰을 즉시 복사하거나 버튼 클릭 한 번으로 자동 발급받는 형식으로 제공됩니다.

Q3. 클룩 할인코드는 어떻게 사용하나요? 어디에 입력하면 되죠? ▼

쿠폰 코드는 직접 등록하거나 결제 단계에서 선택하여 사용 가능합니다. 사전 등록 시 앱의 MY클룩 > 쿠폰 또는 웹의 내 쿠폰 페이지에서 코드 번호를 입력하고 등록하면 됩니다. 등록된 쿠폰은 예약 시 자동 제안되며, 예약 상세정보 입력 단계의 할인 및 쿠폰 코드란에서 선택 적용도 가능합니다. 결제 전 소계 금액에 할인이 정상 적용되었는지 확인이 필요합니다.

Q4. 신규 가입하면 받을 수 있는 할인 혜택이 있나요? ▼

신규 회원 전용 할인혜택이 제공됩니다. 친구 추천 링크로 가입 시 5,000원 상당의 쿠폰 또는 포인트가 적립되며, 첫 결제용 5% 할인 코드(BetterOnApp, HotelOnApp 등 앱전용)도 제공됩니다. 신규 가입자는 가입 보너스와 첫예약 할인코드의 동시 적용이 가능합니다.

Q5. 친구를 초대하면 어떤 혜택이 있나요? ▼

클룩 친구 초대 프로그램은 초대한 사람과 친구 모두에게 혜택이 적용됩니다. 초대 링크를 통해 친구가 가입하면 해당 친구에게 무료 쿠폰 코드 1장이 발급됩니다. 이후 친구가 첫 여행 상품 이용을 완료하면 초대자에게 쿠폰 코드 1장이 추가 제공됩니다. 해당 쿠폰 코드는 다음 예약 시 할인에 사용 가능합니다.

Q6. 여러 개의 할인코드를 중복으로 사용할 수 있나요? ▼

동일 예약에 2개 이상의 쿠폰 코드 동시 적용은 일반적으로 불가능합니다. 클룩 시스템상 결제 화면에서 1개의 할인코드만 사용 가능하며 중복 적용이 되지 않습니다. 다만 특별 프로모션으로 중복사용 가능한 쿠폰이 제공되는 경우도 있으므로(예: 특정 카드할인과 신규코드 동시 적용 등), 각 쿠폰의 이용 조건 개별 확인이 필요합니다.

Q7. 예약을 취소하면 사용했던 할인코드를 다시 돌려받거나 재사용할 수 있나요? ▼

1회용 할인코드는 예약 취소 시 재사용이 불가한 경우가 대부분입니다. 해당 예약에 사용된 쿠폰은 사용 처리되어 환불되지 않습니다. 일정 변경이 필요한 경우 완전 취소보다 날짜 변경 등의 방법이 권장됩니다. 일부 쿠폰은 취소 시 계정으로 반환되기도 하나, 쿠폰 유효기간이 남아 있고 부분환불 상황 등에 한정된 예외입니다. 쿠폰이 유효한데도 취소로 소멸된 경우 고객센터 문의가 가능합니다.

Q8. 쿠폰 코드를 적용했는데 할인이 되지 않아요. 왜 그런가요? ▼

쿠폰 미적용 시 다음 사항의 확인이 필요합니다. (1) 최소 구매금액 충족 여부 - 쿠폰별 최소 결제 금액 조건이 존재합니다. 미충족 시 할인이 적용되지 않습니다. (2) 사용 플랫폼 - 앱 전용 쿠폰은 PC 웹에서 적용 불가하며, 웹 전용 쿠폰도 앱에서 사용할 수 없습니다. (3) 쿠폰 유효기간 및 대상 상품 - 만료 여부와 특정 상품군 한정 여부 확인이 필요합니다. 호텔 전용 쿠폰은 액티비티에 적용되지 않습니다. 위 조건을 모두 충족하는데도 미적용되는 경우, 해당 상품이 쿠폰 적용 제외 상품일 수 있습니다.

Q9. 모든 상품에 쿠폰 코드를 사용할 수 있나요? 혹시 예외가 있나요? ▼

일부 상품은 할인코드 적용이 제한됩니다. 클룩 기프트카드, 일부 교통패스, 식당 바우처 등은 쿠폰 할인 대상에서 제외되는 경우가 있습니다. 쿠폰 적용 제외 상품 목록은 클룩에서 별도 공지되며, 타사 제휴 상품, 입장권 패키지, 기프트형 상품 등이 해당됩니다. 쿠폰 입력 후에도 할인이 미적용되는 경우 해당 상품의 예외 목록 포함 여부 확인이 필요합니다.

Q10. 할인코드마다 유효 기간이 있나요? 어떻게 알 수 있죠? ▼

모든 할인코드에는 만료일이 설정되어 있습니다. 프로모션 안내에 사용 가능 기한이 명시되며, 클룩 앱 또는 웹의 내 쿠폰함에서도 만료일 확인이 가능합니다. 유효 기간 경과 시 코드 사용이 불가하므로 기간 내 예약 완료가 필요합니다. 예산 소진 시 유효기간 전 조기 종료될 수 있습니다.

Q11. 할인코드 사용에 결제 통화나 결제 수단 제한이 있을 수도 있나요? ▼

일부 쿠폰은 특정 통화 결제 시에만 적용되거나 특정 결제수단에 한정됩니다. 글로벌 카드 프로모션 코드는 USD 결제 시 적용되는 경우가 많고, 네이버페이 쿠폰은 원화(KRW) 결제 + 네이버페이 수단 사용 시에만 적용됩니다. 앱 결제 전용(예: BETTERONAPP)이거나 한국어 사이트 전용으로 발급되는 쿠폰도 존재합니다. 쿠폰 약관의 결제조건(통화, 플랫폼, 수단) 확인 후 조건에 맞게 결제해야 할인이 적용됩니다.

Q12. 카드 할인 프로모션과 쿠폰코드를 동시에 받을 수도 있나요? ▼

기본적으로 1건의 예약에는 1개의 할인혜택 유형만 적용됩니다. 카드 프로모션이 쿠폰코드 형태로 제공되는 경우가 많아(코드 2개 중복 불가 원칙), 카드할인 코드 입력 시 다른 쿠폰은 사용 불가합니다. 카드사 즉시할인(결제 단계 자동감액)처럼 별도 코드 입력이 불필요한 행사의 경우 추가 쿠폰코드 입력이 가능한 예외가 있으나, 일반적으로 카드 제휴코드와 다른 할인코드의 중복 사용은 불가합니다.

Q13. 클룩 포인트(Klook Credits)나 적립금도 할인코드와 함께 사용할 수 있나요? ▼

포인트는 쿠폰 코드와 병행 사용이 가능합니다. 클룩 포인트(적립금)는 현금처럼 사용되며 쿠폰 코드와 별도의 할인 수단이므로, 결제 시 포인트 사용과 쿠폰코드 적용이 동시에 가능합니다. 단, 포인트 사용액을 제외한 실제 결제금액에만 쿠폰 할인이 적용됩니다. 예: 50,000원 상품에 5,000원 포인트 사용 후 잔여 45,000원에 10% 쿠폰 적용 시 4,500원이 할인됩니다. 포인트는 유효기간이 있으며 전액 결제는 불가하므로 일부 금액은 카드 등으로 결제가 필요합니다.

Q14. 클룩에는 멤버십 등급에 따른 추가 할인혜택도 있나요? ▼

클룩은 구매실적에 따라 Explorer, Gold 등 멤버 등급을 부여하며, 등급별 리워드 쿠폰 및 추가 적립 혜택이 제공됩니다. Explorer, Gold 회원에게는 전용 할인코드 및 특별 프로모션 초대가 제공되기도 합니다. 멤버십 관련 쿠폰은 자동 지급되는 경우가 많으며, 내 프로필의 리워드 및 쿠폰 섹션에서 확인 가능합니다.

Q15. 그래도 쿠폰 사용에 문제가 있다면 어떻게 하나요? ▼

위 사항을 모두 확인한 후에도 쿠폰 적용에 문제가 있는 경우 클룩 고객센터로 문의 가능합니다. 클룩 고객센터는 연중무휴 이메일(support@klook.com) 및 전화(02-3478-4131, 평일 9시~18시) 상담을 제공하며, 24시간 실시간 채팅도 지원됩니다. 쿠폰 코드와 오류 내용을 준비하여 문의하면 해결이 가능합니다. 기본적인 문제는 FAQ 센터에서도 확인 가능합니다.
