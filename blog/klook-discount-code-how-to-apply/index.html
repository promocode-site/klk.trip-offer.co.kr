클룩 할인코드, 언제 어디서 입력할까

클룩에서 여행 상품을 예약할 때는 결제 마지막 단계에서 할인코드를 입력하는 칸이 따로 있습니다. 원하는 상품을 장바구니에 담은 뒤 결제 페이지로 넘어가면 "프로모션 코드" 또는 "할인코드"라고 적힌 입력란이 보이는데, 이 칸에 코드를 넣고 적용 버튼을 누르면 할인 금액이 바로 반영됩니다. 클룩 할인코드는 상품 종류나 시즌에 따라 계속 바뀌기 때문에, 예약 전에 어떤 코드를 쓸 수 있는지 한 번 확인하고 넘어가는 것이 좋습니다.

코드를 입력하는 시점은 결제 정보를 입력하기 전이어야 합니다. 결제가 이미 완료된 뒤에는 코드를 뒤늦게 적용할 수 없으므로, 최종 결제 버튼을 누르기 전에 할인 여부와 할인 금액을 확인하는 습관을 들이는 것이 안전합니다. 앱과 웹사이트 모두 입력란 위치는 비슷하지만, 일부 코드는 앱에서만 적용되는 경우도 있으니 결제 전 화면을 잘 살펴보는 것이 좋습니다.

사진: naipo.de / Unsplash

결제 단계에서 할인코드 적용하는 방법

먼저 예약하려는 상품을 선택하고 날짜와 옵션, 인원수를 정확히 입력합니다. 이후 장바구니 또는 바로 예약 화면으로 이동하면 결제 금액 아래쪽에 할인코드 입력란이 나타납니다. 이 칸에 코드를 대소문자 구분 없이 정확히 입력한 뒤 "적용" 버튼을 누르면, 할인 금액이 적용되어 최종 결제 금액이 다시 계산됩니다.

코드가 정상적으로 적용되면 화면에 할인된 금액과 원래 금액이 함께 표시됩니다. 이 화면에서 할인이 제대로 반영되었는지 한 번 더 확인한 뒤 결제 수단을 선택해 결제를 진행하면 됩니다. 코드는 상품마다, 또는 회원 등급이나 결제 수단에 따라 적용 여부가 다를 수 있어서, 코드를 입력했는데도 금액이 바뀌지 않는다면 다른 코드로 다시 시도해 보는 것도 방법입니다.

최신 코드와 세부 조건은 자주 바뀌므로, 예약 직전에 클룩 할인코드 쓰러 가기 페이지에서 현재 적용 가능한 코드를 다시 한번 확인하는 것을 추천합니다.

상품별로 다른 할인코드 확인하기

클룩 할인코드는 상품 카테고리마다 다르게 운영되는 경우가 많습니다. 예를 들어 유럽 투어 상품에는 KLKEUTOUR20 코드로 20% 할인(최대 50,000원)을 받을 수 있고, 일본 도쿄스카이트리 입장권에는 TKSKYTREE15 코드로 15% 할인(최대 3,500원)이 적용됩니다. 교토 팀랩 관련 상품은 TEAMLABKYOTO12 코드로 12% 할인(최대 4,000원), 다른 팀랩 상품은 TEAMLAB16 코드로 16% 할인(최대 2,800원)을 받을 수 있습니다.

앱으로 예약할 때만 쓸 수 있는 코드도 있습니다. BETTERONAPP 코드는 앱 예약 시 5% 할인(최대 10,000원), HOTELONAPP 코드는 호텔 상품 앱 예약 시 5% 할인을 제공합니다. 이 밖에도 DISCOUNT, D8452B처럼 별도 조건이 표기되지 않은 코드도 있으니, 상품 결제 화면에서 여러 코드를 차례로 입력해 보면서 어떤 코드가 실제로 적용되는지 확인해 보는 것이 좋습니다.

할인코드 적용이 안 될 때 확인할 점

코드를 입력했는데도 할인이 반영되지 않는다면 몇 가지를 먼저 점검해 보는 것이 좋습니다. 우선 코드에 오타가 없는지, 대소문자를 정확히 입력했는지 확인합니다. 다음으로 해당 코드가 지금 예약하려는 상품 카테고리에 적용되는 코드인지 살펴봐야 합니다. 앞서 설명했듯 일부 코드는 특정 상품이나 앱 예약에만 적용되기 때문에, 다른 상품에 입력하면 반영되지 않을 수 있습니다.

또한 할인 한도가 정해져 있는 코드는 결제 금액이 낮을 경우 할인율만큼 그대로 빠지지 않고 한도 내에서만 할인될 수 있습니다. 예를 들어 최대 할인 금액이 정해진 코드는 상품 가격이 그보다 낮으면 할인율 전체가 아닌 실제 할인 가능한 금액만 적용됩니다. 이런 점을 고려해 예상 결제 금액과 실제 할인 금액을 결제 전 화면에서 다시 확인하는 것이 좋습니다.

코드가 계속 적용되지 않는다면 코드 자체가 만료되었거나 조건이 바뀌었을 가능성도 있습니다. 이럴 때는 클룩 할인코드 페이지에서 지금 사용할 수 있는 코드 목록을 다시 확인한 뒤, 가장 최근 코드로 다시 시도해 보는 것을 추천합니다.

자주 묻는 질문

Q. 할인코드는 한 번에 여러 개 같이 쓸 수 있나요? A. 대부분의 경우 결제 한 건에는 코드 하나만 적용됩니다. 여러 코드를 입력해도 마지막에 적용한 코드나 먼저 적용된 코드만 반영되는 경우가 많으니, 상품에 맞는 코드 하나를 골라 입력하는 것이 좋습니다.

Q. 결제를 마친 뒤에도 할인코드를 적용할 수 있나요? A. 결제가 완료된 이후에는 할인코드를 소급 적용할 수 없습니다. 반드시 결제 버튼을 누르기 전, 결제 금액을 확인하는 화면에서 코드를 입력하고 할인이 반영된 것을 확인한 뒤 결제를 진행해야 합니다.

Q. 앱과 웹사이트 중 어디서 예약해야 더 많은 코드를 쓸 수 있나요? A. BETTERONAPP, HOTELONAPP처럼 앱 전용으로 제공되는 코드가 있어서, 앱으로 예약하면 쓸 수 있는 코드 선택지가 조금 더 넓어질 수 있습니다. 클룩 할인코드 쓰러 가기에서 앱과 웹 모두에서 사용 가능한 코드를 비교해 보는 것도 방법입니다.
